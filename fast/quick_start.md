# 快速入门

## 开始使用UWAN智联
UWAN智联可以帮助你实现门店网络、分支机构网络的智能组网和统一管理。可以结合UGN云联网，轻松实现异地、异构网络的互联互通。

!> 使用UWAN前，请确保您已注册UCloud账号并完成实名认证。

### 操作流程概览

使用UWAN智联的完整流程如下：

1. **申请UWAN虚拟路由器** — 创建虚拟路由器实例，获取公网IP
2. **创建CE客户网关** — 将本地网关信息注册到UCloud侧
3. **创建VPN隧道** — 配置IKE/IPSec参数，建立加密通道
4. **加入云联网**（可选）— 通过UGN云联网实现跨地域、跨网络互通

---

### 步骤一：申请UWAN虚拟路由器

在控制台上点击【全部产品】—【网络】—【智联 UWAN】—【UWAN虚拟路由器管理】TAB页，进入UWAN虚拟路由器管理页面：

![快速入门-step1](/images/快速入门-step1.png)

点击【申请UWAN虚拟路由器】，进入创建页面。

---

### 步骤二：配置虚拟路由器参数

#### 2.1 选择地域与规格

选择「地域」，并选择UWAN规格（当前支持站点入云型（IPSec协议））。

!> UWAN虚拟路由器创建后地域不可更改，请根据您的网络需求选择合适的地域。

![快速入门-step2.1](/images/快速入门-step2.1.png)

#### 2.2 填写基本信息与带宽包配置

填写虚拟路由器名称，并对带宽包进行配置：

| 配置项 | 说明 |
|--------|------|
| 虚拟路由器名称 | 自定义名称，便于识别管理 |
| 购买数量 | 一次可申请多台虚拟路由器 |
| 带宽 | 接入带宽大小，单位Mbps |
| 带宽包名称 | 自定义带宽包名称 |

![快速入门-step2.2](/images/快速入门-step2.2.png)

#### 2.3 确认订单

填写完成后，点击【立即购买】，进入订单确认页面。确认配置和费用信息无误后，点击【立即支付】完成创建。

![快速入门-step2.3](/images/快速入门-step2.3.png)

#### 2.4 查看公网IP

支付成功后，返回UWAN虚拟路由器管理页面，即可看到新创建的虚拟路由器。

![快速入门-step2.4](/images/快速入门-step2.4.png)

点击【详情】，在概览页面可查看自动分配的公网IP地址。此公网IP地址为UWAN虚拟路由器侧公网IP，用于与CE侧设备建立公网连接。

![快速入门-step2.5](/images/快速入门-step2.5.png)

---

### 步骤三：创建CE客户网关

CE客户网关是一个虚拟网关实例，是您本地网关在UCloud侧的投射，用于覆盖节点网络出口设备通过VPN连接到UWAN虚拟路由器的接入场景。

在【CE客户网关管理】TAB页，点击【创建CE客户网关】。

![快速入门-step3.1](/images/快速入门-step3.1.png)

填写以下配置信息：

| 配置项 | 说明 |
|--------|------|
| 所属虚拟路由器 | 选择已创建的UWAN虚拟路由器 |
| IP接入方式 | 支持「静态IP接入」和「动态IP接入」两种方式 |
| 公网地址 | CE侧设备的公网IP地址（静态IP接入时填写） |
| 网关名称 | 自定义网关名称 |

!> 请按实际情况选择静态IP或动态IP接入方式。静态IP接入需填写CE侧设备的固定公网IP地址；动态IP接入适用于CE侧无固定公网IP的场景。

![静态IP接入](/images/静态IP接入.png)
![动态IP接入](/images/动态IP接入.png)

网关创建完成后，可点击【创建隧道】继续配置VPN隧道。

![快速入门-step3.2](/images/快速入门-step3.2.png)

---

### 步骤四：配置VPN隧道

VPN隧道配置包含四个步骤：基础配置 → IKE设置 → IPSec设置 → 管理设置。

#### 4.1 基础配置

填写预共享密钥（PSK），用于IKE协商时的身份认证。

!> 预共享密钥需与CE侧设备配置保持一致，否则隧道无法建立。

![快速入门-step4.1](/images/快速入门-step4.1.png)

#### 4.2 IKE设置

配置IKE（Internet Key Exchange）参数，包括IKE版本、加密算法、认证算法、DH组、SA超时时间等。默认值适用于大多数场景，如无特殊需求可保持默认。

!> 若CE为动态IP接入，CE侧端口ID类型无法自动配置，需自行填写。

![快速入门-step4.2](/images/快速入门-step4.2.png)

#### 4.3 IPSec设置

配置IPSec参数，包括加密算法、认证算法、PFS DH组、SA超时时间等。

在CE侧网段中填写本地网络的网段信息（每行一个网段），例如：`172.16.1.0/24`。

!> CE侧网段不可与对端网段重复或有交集。感兴趣流模式需手动配置CE侧网段和UWAN侧网段；BGP模式需额外填写BGP配置。

![快速入门-step4.3](/images/快速入门-step4.3.png)

#### 4.4 管理设置

填写隧道名称，便于后续管理和识别。

![快速入门-step4.4](/images/快速入门-step4.4.png)

#### 4.5 创建完成

点击【确定】后，UWAN虚拟路由器侧的VPN配置完成。

![快速入门-step4.5](/images/快速入门-step4.5.png)

您需自行完成CE侧VPN配置，即可完成CE客户网关到UWAN虚拟路由器的网络连接。

!> 当您将多个CE客户网关连接到同一台UWAN虚拟路由器上后，这多个CE客户网关下的节点网络即可通过UWAN虚拟路由器实现内网互通。

---

### 步骤五：将UWAN虚拟路由器加入云联网

如果您需要实现多个节点网络的跨地域互通，或者在不同类型的网络之间进行组网（例如打通办公室网络和公有云VPC网络），则需要将UWAN虚拟路由器加入云联网，通过UGN云联网实现异构异地网络的联通。

点击【UWAN虚拟路由器管理】—【详情】—【概览】，查看此台UWAN虚拟路由器所关联的云联网信息。在云联网信息区域，点击「关联云联网」。

![快速入门-step5.1](/images/快速入门-step5.1.png)

在弹窗中选择云联网所属项目和云联网实例，点击【确定】即可将UWAN虚拟路由器加入云联网。

!> 关联云联网前，需先在云联网产品页面创建云联网实例。

![快速入门-step5.2](/images/快速入门-step5.2.png)

您也可以前往云联网产品页面进行关联操作：点击「云联网管理」进入云联网产品页面，点击【管理网络实例】—【关联网络实例】，选择需要加入云联网的UWAN虚拟路由器，点击确认即可。
