# CPE智能网关硬件手册

## 型号与参数

| 属性 | 规格 |
| ---- | :--- |
| 产品 | UCPE3600 |
| 结构尺寸 | 240mm × 155.5mm × 40mm |
| LAN口 | 支持 1Gbps 接入带宽，提供 4 个 RJ45 端口 |
| WAN口 | 支持 1Gbps 接入带宽，提供 2 个光纤端口 / 2 个 RJ45 端口（Combo） |
| Console口 | 提供 1 个 RJ45 端口 |
| USB | 1 个 USB 2.0 Type-A 接口 |
| 指示灯 | 电源状态 / 云互联状态 / 报警状态 / LTE状态 / Wi-Fi 状态 / 用户状态指示灯 |
| 电源 | 本地供电 DC 12V/3A |
| SIM卡插入口 | 1 个内嵌式 SIM 卡插入口，支持 Mini-SIM 卡 |
| LTE模组 | 选配 |
| Wi-Fi | 选配 |
| 天线 | 选配 |
| 工作环境 | 温度 0°C ~ 45°C，海拔高度 < 5000m，相对湿度 5% ~ 95%，非凝露 |
| 存储环境 | 温度 -40°C ~ +70°C，相对湿度 5% ~ 95%，非凝露 |

## 性能指标

以下性能指标为隧道加密后的转发性能。

**pps 性能分析：**

| 帧长 | 64 | 128 | 256 | 512 | 1500 (MTU) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| UCPE3600 | 13.1k | 31.7k | 39.8k | 43.5k | 40.9k |

**bps 性能分析：**

| CPE型号 | 加密私网带宽 |
| :--- | :--- |
| UCPE3600 | 665 Mbps |

> 加密私网带宽可达 500 Mbps（512字节帧长基准），峰值 665 Mbps。
