# 监控指标

本文档说明 UWAN 智联和 CPE 智能网关提供的监控指标，帮助您了解网络运行状态和排查问题。

---

## UWAN 虚拟路由器监控

您可以在【UWAN 虚拟路由器-详情-监控】页面查看以下指标。

### 隧道状态

| 状态 | 说明 |
|------|------|
| UP | IKE SA 和 IPSec Child SA 均已建立，隧道正常 |
| DOWN | IKE SA 或 Child SA 异常，隧道不可用 |

> 隧道状态通过检测 IKE SA（ESTABLISHED）和 Child SA（INSTALLED）判定，两者均正常时状态为 UP。

### 带宽指标

| 指标 | 说明 | 单位 |
|------|------|------|
| 入向带宽 | 从 CE/CPE 流入 UWAN 虚拟路由器的数据速率 | bps |
| 出向带宽 | 从 UWAN 虚拟路由器流向 CE/CPE 的数据速率 | bps |
| 总带宽 | 入向 + 出向带宽之和 | bps |

> 带宽上限限制的是出入向总量（入向 + 出向之和不超过带宽包额度）。

## CPE 智能网关监控

您可以在控制台 CPE 智能网关详情页查看以下监控数据。

### 系统资源

| 指标 | 说明 |
|------|------|
| CPU 使用率 | CPE 设备的 CPU 使用百分比 |
| 内存使用率 | CPE 设备的内存使用百分比 |
| 磁盘使用率 | CPE 设备各分区的磁盘使用百分比 |

### VPN 状态

| 状态 | 说明 |
|------|------|
| Active | IPSec VPN 隧道正常，SA 已建立 |
| Inactive | IPSec VPN 隧道异常，SA 未建立或 strongSwan 服务未运行 |
| Unknown | 无法获取 VPN 状态 |

### 链路带宽

| 指标 | 说明 |
|------|------|
| WAN 口出向带宽 | CPE WAN 口发送数据速率 |
| WAN 口入向带宽 | CPE WAN 口接收数据速率 |

> 每条 WAN 口分别统计，支持多 WAN 口场景。

### TLS 证书

| 指标 | 说明 |
|------|------|
| 证书生效时间 | TLS 证书的生效起始时间 |
| 证书过期时间 | TLS 证书的到期时间 |

> CPE 与 UWAN 控制器之间通过 TLS 加密通信，证书过期后 CPE 将无法与控制器建立连接。请在证书到期前联系客服更换。

---

## BGP 路由信息

您可以在【UWAN 虚拟路由器-详情-路由表】页面查看 BGP 路由信息。

### 路由表字段说明

| 字段 | 说明 |
|------|------|
| 目的网段 | 从 CE 侧通过 BGP 学习到的子网网段 |
| 资源 ID | 发布此网段的网关资源 ID |
| 下一跳网关类型 | 网关资源 ID 对应的网关类型（CE 客户网关或 CPE 智能网关） |

> 仅 BGP 模式的 VPN 隧道会自动学习路由。感兴趣流模式和目的路由模式的网段在创建隧道时手动配置，不会出现在路由表中。

### 路由排查提示

- 如果路由表中缺少预期的路由条目，请检查 BGP 邻居状态是否为 Established
- 跨地域路由需确认 UWAN 虚拟路由器已关联云联网（UGN）
- 如果新加入的节点网络路由未出现，可能是网段与已有网络冲突
