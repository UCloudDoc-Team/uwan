# 操作指南

!> 如果您是第一次使用UWAN，建议先阅读[快速入门](/fast/quick_start.md)，按流程完成UWAN虚拟路由器、CE客户网关和VPN隧道的创建。

---

## 管理UWAN虚拟路由器

当您创建了多个UWAN虚拟路由器时，您可以在UWAN虚拟路由器管理页面，对UWAN虚拟路由器进行管理。

![usage9.5](/images/usage9.5.png)

您可以在详情页查看UWAN虚拟路由器详细信息，包括基本信息、关联的云联网信息，以及查看关联的UWAN跨域带宽包。

![usage10](/images/usage10.png)

---

## 查看路由信息

您可以在【UWAN虚拟路由器-详情-路由表】页面查看此台UWAN虚拟路由器从CE侧所接收到的路由信息。目的网段代表从CE侧学习到的子网，资源ID指发布此网段的网关的资源ID，下一跳网关类型，即网关资源ID所对应的网关类型。

![usage11](/images/usage11.png)

---

## 隧道参数参考

以下列出VPN隧道创建和编辑时可配置的各项参数说明与默认值，供您参考。创建流程请参阅[快速入门](/fast/quick_start.md)。

### IKE参数说明

IKE（Internet Key Exchange）用于在VPN隧道两端协商建立安全连接。IKE目前支持V1和V2版本。

> 使用默认配置时，如果隧道连接由CE客户网关发起，UWAN虚拟路由器为接受端时，UWAN侧做协商。如果UWAN虚拟路由器发起连接，CE客户网关作为接受端时，则以默认配置发起，需要对端配置协商模式或相同配置才能建立起隧道。

| 配置项 | 说明 |
|--------|------|
| 加密算法 | IKE协商过程中使用的报文加密算法，支持aes128、aes192、aes256和3des，默认为aes128 |
| 认证算法 | IKE协商过程中使用的报文认证算法，支持md5、sha1和sha2-256，默认为sha1 |
| 协商模式 | IKE协商过程中使用的协商模式，支持主模式和野蛮模式，默认为主模式 |
| DH组 | IKE协商过程中使用的Diffie-Hellman组，支持1、2、5、14、15和16，默认为15 |
| 本端ID类型 | 描述本端VPN网关设备的ID，支持自动识别、IP地址标识和域名标识，默认为自动识别 |
| 对端ID类型 | 描述对端VPN网关设备的ID，支持自动识别、IP地址标识和域名标识，默认为自动识别 |
| SA超时（时间） | Security Association的超时时间，范围600-604800秒，默认为1080秒 |

!> 若CE为动态IP接入，CE侧端口ID类型无法自动配置，需自行填写。

### IPSec参数说明

IPSec（Internet Protocol Security）用于在VPN隧道中加密传输数据。

> 使用默认配置时，协商逻辑与IKE一致：由发起端按照默认配置发起协商，对端需配置协商模式或相同配置才能建立隧道。

| 配置项 | 说明 |
|--------|------|
| 加密算法 | IPSec协商过程中使用的报文加密算法，支持aes128、aes192、aes256和3des，默认为aes128 |
| 认证算法 | IPSec协商过程中使用的报文认证算法，支持md5、sha1和sha2-256，默认为sha1 |
| SA超时（时间） | Security Association的超时时间，范围1200-604800秒，默认为3600秒 |
| SA超时（流量） | IPSec的Security Association超时流量，范围8000-2000000字节，默认使用SA超时（时间） |
| 安全协议 | IPSec使用的安全协议，支持AH和ESP，默认ESP |
| PFS DH组 | 是否开启PFS功能，支持Disable、1、2、5、14、15和16，默认Disable |

### IPSec路由模式说明

UWAN VPN隧道支持三种IPSec路由模式，决定了流量如何引导进入隧道：

#### 感兴趣流模式

基于兴趣流（Policy-based）路由。您需要手动配置CE侧网段和UWAN侧网段，只有匹配感兴趣流的流量才会进入隧道。

- 适用于明确知道需要互通的网段范围的场景
- 配置时需在「CE侧网段」中填写本地网络网段（每行一个，最多10个），例如 `172.16.1.0/24`

#### BGP模式

基于BGP动态路由。隧道建立后自动通过BGP交换路由信息，无需手动配置网段。

- 适用于网段较多或经常变化的场景
- 选择BGP模式后，需额外填写以下BGP配置：

| 配置项 | 说明 |
|--------|------|
| 系统自治号 | BGP自治系统号（ASN） |
| BGP隧道网段 | 隧道建立BGP邻居所使用的网段，格式为 `169.254.x.x/30` |
| BGP地址 | 本端BGP地址 |

- BGP模式下「CE侧网段」不可见，路由信息通过BGP自动学习

#### 目的路由模式

基于目的路由。隧道协商为全网段 `0.0.0.0/0`，通过路由引导流量进入隧道。

- 适用于所有流量均需进入隧道的场景（如全流量上云）
- 配置方式与感兴趣流模式基本相同，但隧道协商网段固定为 `0.0.0.0/0`

!> 不同路由模式下，CE侧设备的VPN配置方式也不同，请根据所选模式在CE侧做相应配置。

## 删除资源

### 删除UWAN虚拟路由器

您可以在【UWAN虚拟路由器管理】页面对UWAN虚拟路由器进行删除操作。为防止误操作导致批量网络中断，在删除UWAN虚拟路由器之前，您需要先删除此虚拟路由器下所连接的CE客户网关，并解除和云联网的关联。

![usage17](/images/usage17.png)

### 删除CE客户网关

您可以在【CE客户网关管理】页面对CE客户网关进行删除操作。删除后会断开VPN连接，终止您本地网络到UWAN虚拟路由器的网络连接，请谨慎操作。

![usage18](/images/usage18.png)
